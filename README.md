# 家里都好

1995年豫北县城，一个代写书信的小摊。单文件文字冒险。

## 玩法

- 打开即玩：https://inklotus007.github.io/jialiandouhao/
- 点「进 摊」→「新来一位」写个名字，就是你的档。
- 各人各档，进度互不相扰。换设备：同一名字接着写。

## 存档

- **配了云端令牌**（页面底部「云端设置」贴 fine-grained token，需本仓库 Contents 读写权限）：档存 GitHub 仓库 `saves/` 目录，跨设备同步。
- **没配令牌**：也能玩，档只存本机浏览器。
